# 东方符卡礼物设计

五款符卡礼物（反魂蝶、梦想封印、Master Spark、幻世 The World、永夜返·光明之刻）的动画、美术与音效设计记录。物品、礼物与获取方式以 `Configs/Items/`、`Configs/SlotMachine/Lottery.json` 为准。

## 共同设计

共同节奏为 Q 版人物登场、抬手蓄力、释放特征弹幕、收势淡出。人物保持统一线条和适量服饰细节，但保留各自的脸型、配色、神态与动作。每人拆分为头部、躯干、下装与双脚、后发、左右手臂六张透明素材，通过腰部、颈部和肩部支点连续运动；两臂使用 `GiftJointMesh` 网格权重过渡，袖根固定、手部跟随转动，头发与裙摆延迟跟随；魔理沙另有开炮后仰和手臂后坐动作。动画由共享 `Shared/TouhouRig.lua.txt` 使用现有 DOTween 接口编排，无需额外骨骼动画插件。人物固定在屏幕中心，随目标方向转身，弹幕从人物周围飞向目标。蓄力时，人物背后的蓝色六芒星法阵旋转并放大，释放后淡出。法阵使用透明美术素材，各礼物包各自引用一份，保持资源隔离。

## 各款符卡

- **幽幽子／反魂蝶**：八分盛开的西行妖作为半透明背景板，背后蓝紫至绯红的大扇面在 0.62 秒开始快速展开。两波主弹幕仍从人物面前发出，每波三排、每排十二只较大的彩色蝴蝶。每波主弹幕快到目标时才发射激光，第一波两束，第二波补中央第三束，光束在 0.38 秒内逐渐伸向目标。扇面左右两个固定点各发射一排十只蝴蝶，以目标方向为扇形中轴，固定 64° 扇角、匀速直线扩散，形成相互交错的弧形涟漪；每波配一次附加齐射，共 112 只蝴蝶。全程 6.8 秒。蝴蝶水晶振翅声播放音量为 0.22（原 0.45，约降低 6.2 dB）；每波激光起射时播放独立 0.48 秒短音：三次电流振动后接 3900→780 Hz 快速下降的“咻”，不叠加低频轰鸣。
- **灵梦／梦想封印**：六颗彩色灵珠先环绕召唤，约 2 秒沿不同曲线快速飞出。第一对在 3 秒合击，冲击将其余光球推开；剩下两对再次被吸回，分别在 3.47 秒和 3.97 秒合击，形成三段白光连爆与同步爆炸声。 每次播放洗牌彩球颜色，并随机调整初始相位、飞行曲线、反弹角度和距离；合击时间及快速回吸保持一致。
- **魔理沙／Master Spark**：八卦炉蓄光后释放白色核心、虹色边缘的粗大魔炮，从炉口起约 110 个界面单位内迅速扩张，后段保持等宽圆筒形，沿目标方向贯穿至屏幕外，人物随发射轻轻后仰。释放声音以 110、220、330 Hz 的持续低中频轰鸣和轻微脉动为主体，叠加开炮降调，光柱主体不使用白噪声。 正在释放的同类光束每多一束，纵向宽度增加 22%，最多达到单束的 2.5 倍；彩色光束层只按一个实例计数，释放结束后恢复对应宽度。
- **咲夜／幻世 The World**：黄铜与象牙表盘的怀表配独立指针，六次滴答间隔依次拉长为 0.09、0.16、0.28、0.48、0.83 秒，指针连续转动并逐段减速，在最后一声滴答处停止。2.3 秒一道时空涟漪在 0.42 秒内覆盖全屏，内部逐步变灰；三圈共五十四把飞刀围绕目标列阵，圈半径分别为 112、165、218，每圈相位、单刀角度和半径有随机扰动。4.45 秒开始恢复颜色，飞刀从静止逐渐加速刺入目标。背景由 `GiftScreenEffect` 捕获的屏幕纹理与 `TimeStop.shader` 显示，径向波前扭曲采样、内部去色，恢复时淡出；仅冻结画面，不暂停牌局逻辑。全程 8.2 秒。
- **辉夜／永夜返·光明之刻**：六批共 96 发弹幕（48 星弹、24 黄纸御札、24 蝴蝶）从人物中心展开，在 1.84 秒前全部召出，2.45 秒起先后抛射。召唤位置、静置朝向、曲线、速度、旋转与目标附近落点均有随机变化；轨迹始终大致朝向目标。所有弹幕由深蓝紫的夜色逐渐转成暖白金的昼色。御札采用原作截图中的近方形黄纸、深色符印和发光边缘。

## 源文件与音效

人物分层源图、提示词和导出脚本在 `ArtSources/Gifts/Touhou/`（`rig-generation.json`、`export-rig.ps1`），运行时素材为各礼物目录下的 `rig-*.png`。幽幽子睁眼源图保存在 `Yuyuko/rig-head-open.png`，导出脚本会保留该编辑。法阵、怀表、独立指针与水晶星弹的源图和实际生成提示词在 `SpellEffects/`；当前运行时图片为 `blue-hexagram.png`、`time-clock.png`、`clock-hand.png` 和 `crystal-star.png`。

声音不播放登场或普通阶段切换提示。共使用 13 段自制合成音频：五款蓄力、五款释放，以及咲夜时停、灵梦白光爆炸和幽幽子细激光。四款已确认的蓄力音频保存在 `AudioSources/Gifts/Touhou/Charge/`，重建时原样复制；咲夜的蓄力为连续滴答。音效由 `build_spell_audio.py` 重建，只依赖 numpy，音效保留现有合成版本。背景音乐独立引用用户提供的五份音乐文件，灵梦、魔理沙与辉夜已使用新提供的原曲 Opus，旧录音只留在源素材目录；当前五段音乐均不做录音降噪，只做选段、响度和淡入淡出处理。辉夜按用户指定从原曲 5:10 附近的起音（5:10.505）截取到曲末，约 20.66 秒；灵梦、魔理沙与幽幽子从原起点延长为约 24 秒；咲夜从原起点延长到曲末，约 23.83 秒。其余候选段以附近瞬态对齐起点，再进行响度匹配和淡入淡出。音乐起点与处理参数见 `AudioSources/Gifts/Touhou/Music/edits.json`，重建入口为 `build_theme_music.py --ffmpeg <路径>`。音乐选段和循环衔接的听感由预览试听确认。

运行时脚本：入口在 `Assets/Scripts/UI/Gifts/Lua/`，共享舞台与运动编排在 `Shared/TouhouSpell.lua.txt`、`Shared/TouhouRig.lua.txt`。

樱树、折扇和御札源图与生成提示词在 `Projectiles/`。御札在 Unity Sprite 导入时裁去透明留白，不修改原图像素。

东方符卡 BGM 规则由共享包 `lua/shared` 的 `TouhouMusic.lua.txt` 管理，五款入口通过 `Music.play` 加入：同曲连送共享引用并接着当前进度播放，异曲跳过、不排队；最后一个特效结束后淡出 0.3 秒，期间同曲新礼物可续播。仍有引用时，长音乐片段播完后循环；静音不重置播放进度。通用 C# 音频句柄独立保留音频包，第一份特效销毁不会让后续连送断音。咲夜 BGM 目标响度为 -15 LUFS、播放增益 0.95，比此前约提升 7.3 dB；飞刀声峰值由 0.68 提至 0.82、播放增益由 0.75 提至 1，约提升 4.1 dB，在 4.92 秒播放。
