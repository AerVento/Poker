# 幻想乡绘札局部修正

2026-10-05。范围为10张人体／道具修正、此前确认的7张名字避让，以及方片5、8的译名修正。其他33张正面、牌背不在本轮修改范围内。

## 素材与复现

- `Before/`：本轮修改前19张正式牌面快照。
- `Inputs/`：图像编辑输入。10张结构修正使用原牌面内侧裁切（x=32、y=110、752×994），避免模型重画名字和牌框。
- `Generated/`：内置 image_gen 生成的局部修正稿。历史试稿保留用于比较，不全部采用。
- `generation.json`、`revisions.json`、`extra-revisions.json`、`sword-revision.json`、`followup-generation.json`、`umbrella-redesign.json`：实际提示词、输出来源、迭代记录。反馈后采用妖梦第四稿、姬海棠果第二稿、幽香第六稿的局部；秦心仍用第二稿，其余已认可的修正保留。
- `PreviousPass/`：本次反馈前6张正式牌面快照。`References/`：用户补充的两张妖梦剑具参考，仅用于核对道具设定。
- `Layers/`：透明修补图层及从原空牌面参考图提取的纸纹。原始人物并非独立透明素材；这里是本次新保留的局部修补层。
- `NoNames/`：14张修正后的无名字牌面及3张恢复原插画的牌面，保留原有标准角标和边框。
- `Final/`：19张最终带名字牌面。
- `Comparisons/`：每张完整前后对照、10张结构细节对照、分组总览和204×288／102×144检查图。均为左旧右新。

复现顺序：运行 `compose-retouches.cjs`，再运行 `../IndexPreview/apply-character-names.cjs --preview`，最后运行 `build-comparisons.cjs`。去掉名称导出的 `--preview` 才会覆盖正式 Assets；保留现有 `.meta`。脚本依赖本机 Codex 配套 Node、Sharp、Playwright 和 Chrome，迁移环境时调整依赖路径。
