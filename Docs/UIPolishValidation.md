# UI 精简、契约还款、游戏内任务及结果网格验证

日期：2026-09-09。Unity 2022.3.52f1c1。变更前快照提交：`98aa482`。

## 最终行为

- 删除商城、仓库、每日任务与排行榜中的操作教学和重复限制说明，保留标题装饰、名片介绍和契约完整设定。
- 购物车与箱子入口使用项目金色／墨绿色按钮风格；背景遮罩不缩小按钮矩形命中范围。
- 三种契约改为消耗品，服务端单种库存上限由 1 改为 uint 上限；原实现确实造成只能成功购买一次。保留余额为 0 时免费签约和对应借款，允许后续再次签约。
- 仓库使用契约分别扣除 $1,100 / $11,000 / $110,000，消耗一份库存，对应减少 1 / 10 / 100 年服刑。条件与使用效果分别注册，余额、库存、账本和幂等回执在同一事务提交。失败不扣款、不消耗。
- 游戏内设置直接打开每日任务。服务端只在两手结算阶段或本手真实参与并已 Fold 时放行领奖；删除任务的自动领奖经过相同检查。旁观、等待下一手和未 Fold 的 All-in 玩家不能在手牌进行中领奖。
- 用户确认的口径：奖励立即入账户与背包，筹码下一手可用；低余额条件读取未结算账户余额。结算只应用本手净输赢，并精确核验本手 TaskReward 账本，保留已领取奖励；异常余额变化仍拒绝结算。
- 服刑榜背景在根 Canvas 下等比覆盖全屏。
- 每手结果过滤 Fold 玩家，每排最多四张玩家卡片。每卡自上而下为两张底牌图片、玩家名、牌型名称及五张牌文字、收益；公共牌单独置顶。未摊牌不显示牌型。1/2/3 人以及不足四人的末行均匀居中，不再用微型图片显示组成牌。
