# 标题页商店与排行榜入口迁移

2026-09-07，Unity 2022.3.52f1c1。

## 行为

- 名片商店、财富排行榜仅保留在标题页，位于开始游戏下方；房间列表页的两个旧按钮及监听已删除。
- 未登录时打开登录页，保留所选目标。登录成功后直接进入目标页，返回到标题页。
- 取消登录会清除目标，后续普通登录仍进入房间列表。
- 账户存在上次房间时，房间恢复优先。正在进入房间、已在房间或牌局中时，标题入口不能绕过原有限制。
- 每日任务沿用相同目标选择机制；设置、退出移到同一行，避免菜单加长。
- 本次只修改客户端导航与预制体，没有修改服务端购买、装备、余额或牌局规则。

## 运行检查

- Game.unity 实际 Play Mode，1920×1080 与 1366×768，按钮无重叠。
- 使用 EventSystem 射线确认商店与排行榜按钮未被遮挡，并实际点击进入登录页；目标分别是 Shop、Leaderboard，取消返回 TitlePanel。
- 房间列表运行实例有 4 个按钮，ShopButton 与 LeaderboardButton 均不存在。
- 标题页、房间列表页、登录页及 UIManager prefab：Missing Script / Missing Reference 为 0，Game.unity 无未保存改动。
- 排行榜一服三端通过：Logs/TitleEntries/titlelb-65c0a2f8。三个客户端均从标题页进入、刷新和返回，之后完成两手并离房。最终余额/账本均为 5,530,000，活动手牌 0。
- 商店联机首次运行通过购买、取消、装备和翻页，但旧测试将名片文件名写死为 galaxy-v1，导致进入房间时误报。测试现核对商品目录中的 Artwork 引用，适配已导入的新版资源，仍保留默认款、公开装备 ID 和操作标记检查。
- 断线与恢复一服三端通过：Logs/TitleEntries/titledcp-79df5094。包括预约/取消、断线回标题、重新认证回房间、恢复预约、等待玩家离开、两手和离房。最终余额/账本均为 30,000，活动手牌 0。
- 商店后续重开测试发现标题按钮会保留上一帧的入房禁用状态。TitlePanel 现于 OnEnable 立即刷新控件状态，确保离房后同帧显示标题页即可使用。
- 商店最终一服三端全部通过：Logs/TitleEntries/titleshp-18dc36fb。覆盖标题入口、报价/取消/购买扣款、永久库存、免费装备/默认切换、分页、房间与牌局的实际美术、三手旁观/参战、离房后重开、返回标题。最终余额/账本均为 12,000，活动手牌 0。
- 即时按钮状态另在 Game.unity 实测：入房期间按钮禁用，清除 pending 后重新显示标题页，同帧立即可用。
- 最终 Windows x64 开发构建成功，0 error、3 warning，作业 build-9e12dc2eef；构建仅作本地验证，未发布。排行榜与断线场景使用同轮此前构建，最终构建后完整重跑了受即时按钮状态修复影响的商店场景。
- 测试使用独立本地数据库与端口，已恢复测试前保存的登录偏好。退出 Play Mode，恢复原 Linux Server 目标与 Full HD Game View。
