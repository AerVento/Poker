# 账户与持续牌桌改造问题记录

## 1. 使用规则

本文件只记录在实现 [CashGameMigrationPlan.md](./CashGameMigrationPlan.md) 时发现的重大架构冲突、需求缺口和已经明确延期的风险，不代替普通 bug 列表。

遇到以下情况时，应先新增问题记录，不直接扩大代码修改：

- 现有框架的数据模型与已确认需求明显冲突；
- 需要改变用户可见规则，但需求文档没有答案；
- 可能造成账户冒用、筹码丢失、筹码复制或数据库不一致；
- 需要新增或替换重要第三方依赖；
- 某个安全前提在当前部署环境中不成立。

记录后暂停受该问题阻塞的修改，继续其他互不依赖的工作。只有问题得到明确决定后，才能更新计划并继续对应实现。

## 2. 状态定义

- `Open`：尚未决定，相关实现保持暂停。
- `Deferred`：已确认延期；必须注明当前阶段允许做什么、禁止做什么。
- `Resolved`：已有决定，并已同步到需求计划或实现。
- `Closed`：确认不再构成问题。

## 3. 问题模板

```text
### ISSUE-XXX：简短标题

- 状态：Open / Deferred / Resolved / Closed
- 发现阶段：阶段编号
- 发现日期：YYYY-MM-DD
- 涉及文件：路径与关键类型
- 现状证据：当前代码实际如何工作
- 与需求的冲突：为什么计划无法直接落地
- 风险：不处理或擅自处理会造成什么结果
- 可选方案：列出可行方案及取舍
- 当前决定：尚未决定时写“无”
- 暂停范围：哪些修改暂时不做
- 可继续范围：哪些工作不受影响
```

## 4. 已记录问题

### ISSUE-001：账户密码传输缺少 TLS/WSS

- 状态：Deferred
- 发现阶段：阶段 0
- 发现日期：2026-08-29
- 涉及文件：`Assets/Scenes/Game.unity` 中的 Simple Web Transport 配置。
- 现状证据：当前 `sslEnabled` 与 `clientUseWss` 均为关闭状态。
- 与需求的冲突：本计划会加入用户名和密码登录；公网明文 WebSocket 无法保护传输中的密码和会话信息。
- 风险：攻击者可能窃取登录凭据或会话；仅在数据库中安全哈希密码不能解决传输风险。
- 可选方案：在 Transport 直接配置 TLS/WSS，或由可信反向代理终止 TLS，再把安全连接转发至游戏服务器。
- 当前决定：TLS/WSS 与证书部署进入下一份计划，本次不实现。
- 暂停范围：不得宣称本阶段账户系统已经满足公网安全发布条件，不进行正式公网密码部署。
- 可继续范围：SQLite 账户结构、密码哈希、注册登录逻辑、会话顶号、授权校验和本地集成测试可以继续。
