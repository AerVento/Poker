# 钱包、大厅与牌局交互更新

## 已确认的业务口径

- 美金与筹码独立记账，均为整数，1:1 双向兑换。旧余额仅迁移一次到美金，初始筹码为零。排行榜显示两种货币之和。
- 本手下注、全下、边池和结算仅使用筹码。任务、成就、商店、契约及其他非牌桌奖励和消费使用美金。
- 正在参战且未弃牌时禁止兑换；弃牌后可兑换未投入本手的筹码。旁观、手间等待和房间等待时可兑换。结算以账户当前余额加结算差额，保留弃牌后的兑换。
- 消费美金不足时，仅在可以兑换且可用筹码足够的情况下询问是否兑换精确缺口。确认后的兑换与消费是同一服务端原子操作，报价变化需重新确认。
- 不足一个大盲时转为观战；美金与剩余筹码足以补齐时提供兑换入口。兑换不会自动参战。人数不足时所有成员回到同一房间等待界面，保留观战成员。
- 房间等待界面可切换参战/旁观；参战受座位容量和大盲门槛约束，准备状态独立。

## 成就

- 隐藏成就仍属于原分类，未获得时使用统一标题、描述、问号图标、`?? / ??` 进度和 `??` 奖励。获得后揭示真实内容。
- 排序为未领取的已完成、已领取的已完成、普通未完成、隐藏未完成；同组保留稳定顺序。一键领取覆盖当前分类的全部可领取成就。
- 新隐藏成就「一掷成灰」奖励 $10,000 美金：主动执行 AllIn 前剩余筹码至少 $50,000，该次 AllIn 新投入的筹码扣除未跟注退回后至少 $50,000，并且在所有奖池均未获胜或分得奖池。此前下注不计入本次 AllIn 门槛。
- 例：剩余 $60,000 全下，退回 $15,000 不满足门槛；退回 $5,000 且全部奖池落败则满足。恰好 $50,000 也满足。

## 结果、准备与亮牌

- 客户端仅缓存本房间最近一手结果；离房或断线清除。回看不会发送准备请求。
- 自动结果面板对仍符合条件的本手实际参战者显示「确认并准备」。旁观者和仅预约下一手者不计入确认人数。关闭按钮不算准备。
- 已离房、断线、明确旁观、结算后筹码不足而转旁观的人不阻挡快速开局。所有剩余需确认者确认后跳过手间等待，但开局仍要求足够人数。
- 全员弃牌后的胜者可在当前结算窗口点击自己的结果名片公开底牌，不可撤回。服务器校验并广播，更新可见结果和客户端缓存。下一手开始后关闭亮牌窗口。
- 牌型只使用实际已公开的公共牌及底牌；不足五张不显示五张牌型。补充亮牌事件仅推进牌型类目标，不重复发钱、统计胜场或增加手数，获胜方式仍为对手弃牌。

## 界面与输入

- 标题仅保留开始游戏、设置。大厅提供房间、排行榜、成就、任务、商城、收藏、设置及兑换入口。
- 登录/注册使用独立页签，注册重复确认密码。全局与游戏内设置均提供共享的本地快捷键配置。
- 默认快捷键：F 弃牌，C 过牌/跟注，R 聚焦加注金额，Shift+A 全下；Tab/Shift+Tab 切换表单字段，Enter 确认，Esc 返回。仅顶层面板响应；编辑文本时抑制下注快捷键。
- 游戏界面分离加注金额输入与执行按钮，增加任务、兑换、上手回看入口。观战列表使用可复用开关、眼睛标记和半透明名片；弃牌后操作区域保留「弃牌」。
- WebGL 模板移除导航及 Unity 页脚，填满可用浏览器视口；Canvas 横屏匹配高度、竖屏匹配宽度，并为牌局布局提供竖屏重排。
