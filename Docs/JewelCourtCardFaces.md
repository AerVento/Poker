# 宝石宫廷牌面设计与接入

## 视觉规则

使用确认的纹饰底板 v2：白色圆角、细纸纹、浅色压纹卷草、香槟金交织边线及植物装饰，比例 17:24。左上同时保留大点数与普通花色；黑桃／梅花近黑，红桃／方片红色。右下不放第二组角标。

A～10 无论点数多少，只在右下显示一件花色珠宝。黑桃为蓝宝石，红桃为红宝石，方片为橙红宝石，梅花为祖母绿；有切面、金属镶座、爪镶与碎钻包边。

J/Q/K 只在右下显示单个人物半身像，采用深色轮廓、简化明暗的卡通画风，穿华丽贵族礼服。以经典牌相应人物的身份、发型、冠帽和持物为参考，属于风格化改编。人物胸前首饰属于插画装饰，左上花色承担识别功能。

## 组合与接入

珠宝、人物、底板由 image_gen 生成，完整原图、提示词和透明元素保存在 `ArtSources/CardFaces/JewelCourt/`。点数与左上花色由代码布局，避免模型书写错误。保留共用元素，使用 `export.py` 组合导出 52 张成品，不逐张生成。

正式输出使用 v2 底板，单张 816×1152、RGBA；点数顶部 y=70，花色在点数下方，10 使用较宽区域。珠宝限制在 x=398～744、y=626～1068，人物限制在 x=346～754、y=600～1070 内，保持比例、贴齐右下。坐标为组合像素坐标。

52 张 PNG 位于 `Assets/Sprites/CardFaces/JewelCourt/`，通过商品的 `Cards` 引用 `JewelCourtCards.asset`，使用统一 `CardFaceView.prefab`。牌背已替换为专属 `Back.png`（白金卷草和多色宝石徽章）；本次通用组件改造见 [配置说明](CardAndGiftConfiguration.md)。Sprite 使用 Single、Full Rect、100 PPU、Clamp、Bilinear、无 mipmap、无有损压缩；所有装饰关闭 Raycast Target。

商品 `JewelCourt.asset` 已注册到 `Assets/Resources/SO/Shop/CardFaces/CardFaceCatalog.asset`，ID `jewel-court`，名称「宝石宫廷」，统一物品 ID `cardface-jewel-court`。`JewelCourt.asset` 与 `CatCourt.asset` 的 SO 默认值均为上架、售价 $50,000；经典款与简约款保持免费默认拥有。部署后可由 `Configs/Shop/CardFaces.json` 局部覆盖。没有向现有账户发放或自动装备商品。
