# 任务实施中的待确认事项

2026-09-08。

目前没有发现必须中断实施、且无法依据已确认任务书判断的业务逻辑问题。任务的消费时间、取消不回退、跨日分配、等待领奖、多轮占位等均按用户最后确认的规则实现。

以下是为实现完整功能采用的工程处理，记录便于后续调整：

- 配置编辑保存后重启服务端生效；已有任务继续使用分配时的定义和奖励快照。
- 奖励道具达到持有上限时整笔领取失败，筹码、道具、轮次均不发生部分变更；奖励不会被吞掉，用户处理持有上限后可以重试。
- 随机候选不足时保留空位，不复制已有未完成定义；权重 0 表示不参与抽取。
- 普通道具奖励接入 account_items；同时开发的名片外观系统使用独立发放 API，本期不把名片外观当作普通背包道具。

本轮编译、自动化测试、双平台构建、Windows 与 Linux 的多人验证均已完成，没有新增未决业务规则。验证中发现的测试夹具问题和旧卡片编号重叠已修复。

本次删除功能按最新确认规则实施：删除前自动领取当前一轮奖励，未开始的剩余轮次不发奖；到账失败保留整个任务。固定任务不可删除。不存在新增且无法判断的未决项。
