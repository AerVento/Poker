## 环境与变更

- Unity `2022.3.52f1c1`，场景 `Assets/Scenes/Game.unity`，起点提交 `6b61cfa`，叠加用户原有未提交修改及本轮修改。
- 删除 9 个运行时响应式脚本及 `.meta`（脚本共 2004 行），通过 Unity Editor 移除 11 个 prefab 中的挂载，保存必要的横屏布局参数；清理两个 Editor 迁移工具中的挂载逻辑，以及 GamePanel / RoundResultMsgBox 的调用。
- 保留原生 CanvasScaler、布局组、滚动与按玩家数量排列等功能。CanvasScaler 使用 1920×1080 参考尺寸和 Expand，不再由脚本切换宽高匹配。

- 修复 `NetworkRoom.Results.cs` 的 `BroadcastRoundReady`：先取得接收者数组，再逐个查询、发送准备状态，避免查询座位时同步成员列表使枚举器失效。

## 缺陷与待确认项

1. **已修复：结算广播异常。** 第一轮双方完成河牌过牌后停留在牌桌，未出现结算。调用链为 `OnRoomRoundEnd → BroadcastRoundReady → GetRoundReady → FindSeat → EnsureSeatModel → SynchronizeLegacyLists`，枚举 `MemberNames` 时底层 Players 被重建。日志：`Logs/UiSmoke/Server/errors.log`。修复后独立 server + 两 client 已完成同路径复测。
2. **大厅缺少账户信息。** 登录后的大厅只显示标题与八个入口，没有用户名、美金和筹码；房间列表、房间及设置中可以看到正确账户信息。对应清单 4.1，未通过。证据：`Logs/UiSmoke/B/screen-8.png`。
3. **已确认：结算按奖池领取金额显示，符合设计。** 修复后双方各下注 2，A 余额从 1020 到 1022、B 从 980 到 978，结果卡却显示 A `+$4`、B `$0`。当前 UI 展示的是分得奖池金额 `ChipEarned`。用户后续明确这是预期设计，保留 `+$4` / `$0`，无需改为净输赢；实际筹码变化正确。证据：`Logs/UiSmoke/A3/screen-22.png`、两端对应 JSON；清单 4.4 已更正为奖池领取金额。
4. **连接提示残留／错误状态。** 同机多实例共用 PlayerPrefs，第二客户端曾恢复同一测试账户，正确替换了旧连接。旧客户端重新登录、遇到失效会话后，底层提示密码需重新输入，但上层“正在连接到服务器”仍阻挡输入，取消后又提示连接失败。Editor host 启动也出现已连接却残留连接弹窗。需继续检查连接与认证状态、弹窗生命周期。证据：`Logs/UiSmoke/A2/state-10.json`、`state-14.json`、`Logs/UiSmoke/Editor/state-1.json`。不能将本次多实例共享凭据现象直接认定为服务端串号。
5. **视觉规范尚未全部满足。** 标题按钮区靠近并叠在右侧装饰牌背景上；标题设置仍是文字入口；设置内层和快捷键底板有直角；结算／通用弹窗关闭仍使用文本 ×。此次未扩展为全项目美术重做。证据：`Logs/UiSmoke/A/screen-2.png`、`screen-20.png`、`Logs/UiSmoke/A3/screen-22.png`。
