# 逻辑与 UI 修复记录（2026-09-05）

项目是使用 Unity 2022.3.52f1c1、Mirror、UniTask、uGUI / TextMeshPro 的多人德州扑克游戏，已有账号认证、持久筹码、大厅、房间、旁观、完整下注流程与结算。此次通过 Unity MCP 实际执行代码、控制 Play Mode、修改预制体、运行测试及生成客户端构建。

本轮只修复现有逻辑与界面问题，没有增加游戏功能，也没有升级 Unity 或依赖。

| 问题 | 修复后的行为 |
| --- | --- |
| 多个进程同秒启动时争用同名日志，异常中断网络消息处理 | 默认日志名带唯一标识；初始化或写入失败不会中断游戏；重开日志追加写入 |
| 下注框纠正金额后实际发送值仍是旧值 | 显示金额与提交总额一致，兼容已有下注、最小加注及短筹码全下 |
| 同步覆盖正在输入的金额，连续点击重复发送操作 | 同一行动状态保留输入，请求等待期间禁用操作，失败后恢复 |
| 房间切换后已存在但隐藏的牌桌没有重新显示 | 同步统一处理大厅、房间与牌桌显隐；下一手收起上一手结算 |
| 玩家列表容量固定、空座位显示成玩家 | 按同步容量扩展并隐藏空座位或多余行 |
| 重复同步重置倒计时，离开面板后计时继续 | 相同思考时间不重新计时；换街重置；隐藏时停止；非当前玩家不显示时间 |
| 未公开底牌的玩家被推算出牌型，排序比较不正确 | 只对公开的完整底牌显示牌型；平手比较返回相等；筹码排序避免无符号溢出 |
| 大厅每秒销毁、重建房间按钮，打断点击与焦点 | 按房间 ID 复用条目，面板隐藏时取消自动刷新；创建成功后才进入房间 |
| 房间思考时间接受零、NaN 或无穷大 | UI 与服务端均拒绝非法值；设置仅由等待中的房主提交 |
| 分辨率显示使用去重前索引，首次打开显示错误 | 先生成去重后的列表，再选择当前窗口尺寸；支持非标准窗口尺寸 |
| 弹窗关闭、重复回调与键盘焦点存在问题 | 关闭按钮执行取消语义，回调只执行一次；先关闭再回调；弹窗接管并恢复键盘焦点 |
| 登录等待中无法返回 | 允许取消等待并返回 |
| 牌桌行高过大、顶部状态重叠、设置文字对比不足 | 调整四个现有预制体，缩小玩家行，分开标题与状态栏，统一行动中文标签及设置文字颜色 |

验证结果：

- 初始 88 项 EditMode 测试通过；新增后 106 项全部通过，包括实际 UI 预制体的回归用例。
- Windows Development 构建成功；构建仍有项目原有的未使用事件警告。
- 一个独立服务器和三个独立客户端经过正式 UI 消息处理器，验证注册、建房、入房、准备、跟注、过牌、翻牌下注、转牌、河牌、结算、倒计时、下一手参赛、离房及断线。
- 联机测试完成两手牌后，服务器核对账户与账本均为 30,000，活动牌局为 0，筹码守恒。
- Play Mode 检查了 1920×1080 与 16:10 窗口中的牌桌，以及设置、弹窗、关闭回调、键盘焦点恢复和鼠标遮挡。
- Game.unity 与 UI / Manager 预制体检查未发现 Missing Script 或损坏引用。原有场景修改保留；既有 C# 编码和 CRLF 保留。
- 本地截图、构建和联机报告位于 Logs/UIReview 与 Build/UIReview，不纳入版本控制。

本轮未在 WebGL 浏览器或 Linux 原生服务器上运行，也未覆盖真实互联网延迟、长时间压力测试或全部断线重连组合。部分联机验证使用无图形模式；视觉检查在 Unity Game View 中单独完成。

后续可选功能建议：快捷下注金额（例如半池、满池）、可查看的牌局操作历史、轮到自己行动时的声音提示。这些功能本轮均未添加。
