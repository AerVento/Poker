# UI 视觉更新

本轮更新现有界面的视觉和排版，保留游戏规则、网络协议及现有按钮功能；另修正连接未完成时登录页返回标题的边缘情况。使用 Unity 2022.3.52f1c1，通过 Unity MCP 在 Prefab Mode 中修改和保存资源。

## 视觉规范

| 用途 | 色值 |
| --- | --- |
| 深色背景 | `#0B1719` |
| 面板底色 | `#162B2B` |
| 次要按钮 | `#223D39` |
| 公共牌桌面 | `#163E32` |
| 正文 | `#EEE9DD` |
| 次要文字 | `#A4B9AD` |
| 主操作、筹码与当前玩家描边 | `#D9BC7A` |

- 字体沿用项目已有中文字体；通过字号、颜色及留白区分层级。
- 参考尺寸 1920×1080。页面标题约 44，正文和按钮约 28，辅助说明约 24；玩家行动标记使用较小字号。
- 按钮统一为圆角，区分普通、悬停、选中、按下和不可用状态。
- 新增的背景、圆角、描边与玩家状态图位于 `Assets/Sprites/UITheme`，由 Unity 生成和导入；小尺寸控件使用九宫格拉伸。
- 装饰图形和文本不接收鼠标事件；输入框、按钮及滚动区域保留交互目标。

## 页面调整

- 标题页采用左侧标题和入口、右侧双 A 牌面构图。
- 登录和设置使用一致的表单容器、字段间距、输入框及返回入口。
- 大厅将房间编号、房主与人数对齐，区分房间行背景及选中状态。
- 房间页面左侧列出玩家，右侧集中展示牌桌设置。
- 牌桌左侧为玩家列表，中间为公共牌，下方为底牌、当前玩家信息与行动按钮；庄家、小盲和大盲使用简洁文字标记。
- 通用弹窗与两种结算页统一遮罩、标题、关闭和确认按钮。

本轮运行截图与验证输出保存在 `Logs/UIBeautify`，Windows 构建保存在 `Build/UIBeautify`。这些本地产物不纳入版本控制。


## 引用和交互清理

- 清除牌桌中 6 个指向已不存在控制器的 Animator。原有卡牌脚本直接切换牌面，不依赖这些组件。
- 开启登录输入框的背景，修正紧凑行动标记中的金额裁切。
- 当连接尚未建立、停止连接不会触发断线回调时，登录页仍能返回标题。

## 验证

- 106 项 EditMode 测试全部通过。
- 最终 Windows Development 构建成功（0 error，2 warning）。
- 最终构建以 1 个服务器和 3 个客户端通过两手牌联机测试，包含建房、入房、准备、跟注、过牌、下注、河牌、结算、旁观转入下一手及离房断线；测试日志未发现运行异常，账户与筹码账本总额均为 30,000。
- 在 Play Mode 检查标题、登录、设置、大厅、房间、牌桌、结算及确认弹窗；验证按钮命中、输入框、16 人列表滚动、弹窗关闭及未连接状态返回。
- 在 1920×1080 与 1600×1000 中检查牌桌布局。截图使用本地示例数据。
- 21 个 UI / Manager 预制体检查无 Missing Script 或损坏序列化引用；Game.unity 场景验证通过。
- 6 个新增图像均有 `.meta`；原有 `Game.unity` 场景内容未改动，构建目标已恢复为 Linux。

人工制造“启动连接后同帧取消”的压力场景时，Mirror SimpleWeb 的后台连接线程记录过空引用异常；页面已正确返回。该第三方传输层竞态未在本轮修改。WebGL、Linux 原生运行与更多屏幕比例未重新验证。
