## 契约规则

- 原有实现确实是不可消耗，单种持有上限 1，从而只能成功购买一次。
- 保留余额为 0 时签约、获得 1,000 / 10,000 / 100,000 的原有购买条件与效果。
- 使用时扣除 1,100 / 11,000 / 110,000 并消耗一个契约；年数按当前库存计算，分别减少 1 / 10 / 100 年。
- 不增加三选一、每日限购、升级链或新冷却；库存上限使用 uint 范围。
- 已有库存 ID/GUID 不变，升级后直接成为可偿还的消耗品。
- 按钮统一“无法购买”；允许购买且价格为 0 时显示“免费购买”。特殊条件写入完整物品介绍。
