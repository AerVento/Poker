# 对话形成的约定与案例

整理自本项目 2026-09-09 至 2026-09-10 的成就制作对话。记录可复用的协作方法和易误解条件，不保存逐字聊天，也不复制完整目录。完整规则见仓库根目录 `Docs/Systems/Achievements.md`。

## 协作过程

1. 用户提供名称、类别、自然语言条件与奖励，描述中可能包含只为让 Agent 理解而补充的细节。
2. Agent 只指出会影响结果的歧义，用具体建议帮助回答，例如“按最佳五张牌的准确类别，不要求获胜”。
3. 用户逐项确认后直接实施，不重复追问，也不要求为普通实现选择再批准。
4. 精确设计转成简洁文案；用户表示名称不满意时协助优化，详情仍可展开。
5. 图标可以复用，但用户强调不能因为制作麻烦总用旧图，应按主题主动生成，并保持整套风格一致。
6. 完成代码、文案、资源接入及范围内检查后交付，如实列出未验证项。

这是协作方式，不是每次必须发问、改名或生成新图的固定清单。清晰的设计可以直接实现。

## 规则如何逐步澄清

### 财富与牌型

- 既有财富成就的“赚取”落实为净盈利，累计只加正数；不能据此假定未来“购买金额”“收入”也等于净盈利。
- 普通牌型成就要求最终摊牌且未弃牌，不要求赢，按最佳五张牌的准确类别判定，不向低级牌型连带解锁。
- 食物链成就的“严格大于”指牌型类别不同，同为一对、仅点数不同不够；并列赢家可以同时获得。
- “一对 2 获胜”指最佳牌型恰好是一对 2，赢得任意实际主池或边池即可。
- 皇家同花顺在未弃牌时组成即可：先组成后弃牌保留，先弃牌后公共牌补成不算。

### 多来源与刑期

用户要求把单一牌桌来源扩展为商店购买、仓库使用、收藏装备变化，并支持继续增加来源。因此形成四类来源和类型化订阅，不把其他业务假装成牌局事件。

- 换名片或牌面区分实际换装和重选同一款式，既有成就限定非默认款式。
- 签约对应成功购买，使用契约对应成功还款；赠送影响库存和刑期，但不是主动签约。
- 刑期看当时持有契约对应的当前年数，达到 100／500／1,000 年时解锁，不累计历次借债。解锁后还款不撤销。
- 用户要求优化前七项名称，最终采用“锦衣加身、牌面担当、与魔为契、还债之路、百年之囚、五百年劫、千载沉沦”。这是命名风格示例，不是自动改写后来给定名称的理由。

### 行动、失败与边池

- AK 成就关注翻牌前有效行动导致全下，不仅是点击 AllIn；无需等到结算。
- AA 成就关注翻牌前累计投入门槛，不能叠加各条已经累计的 StreetBet；最终弃牌或一池未得才符合该项条件。
- “大三喜小二元”确认是“双听牌听空”：摊牌时同时差一张同花和一张顺子，均未组成且一池未得。允许卡顺、A2345，不要求两种听牌等同一张牌。
- “史上最强vs现代最强”要求同池恰有两位并列赢家，双方至少葫芦；其他败者可存在，正常奇数筹码分配不影响资格。

### 两项诈唬成就：只问影响结果的问题

用户提出这两项时，Agent 只澄清了三个关键点：后一项缺少奖励、前一项用哪个时点的公共牌比较、后一项跟注及共同奖池的范围。用户确认后完成实现。

- **兵不厌诈，$10,000**：至少到翻牌，有三张公共牌后，靠对手弃牌而未摊牌赢池。按结束时已发出的公共牌分别计算赢家与弃牌者的最佳五张牌，至少一位弃牌者高出赢家两个牌型类别。不补发剩余公共牌。
- **虚张声势，$10,000**：对手先全下，自己同一轮随后跟注或全下，短码跟不上全部金额也可；双方未弃牌进入摊牌，自己以高出至少两个牌型类别的牌赢得双方共同参与的任意主池或边池。
- 已经覆盖对手的短码全下，之后才与第三人争夺边池，不能算作随后跟上这名对手全下；赢其他无关边池也不满足共同奖池要求。
- 两级是“高牌→一对→两对→三条→顺子→同花→葫芦→四条→同花顺”的类别差，不是点数差。

这些口径属于对应成就，新设计的获胜范围、阶段及累计方式仍由其要求决定。

## 视觉与验证的经验

用户发现新旧图标不同风格后，要求统一并为后续 Agent 留规范。当前准则是一套墨绿、金色圆形浮雕徽章，详见 [图标规范](icon-style.md)。

诈唬两项分别用“狐狸面具藏牌”和“分开面具显露黑桃”。第二张前两次把棋盘格画进 RGB 图片，用完整风格提示重新生成后得到真实 RGBA。教训是检查 alpha，不把预览棋盘格当透明证据，也不把一次失败变成无限重试要求。

当时用户明确无需跑测试，交付仅做 Unity 编译、目录与资源检查，未运行游戏功能测试或构建。以后应读取当前会话约定，不能引用历史检查宣称新改动通过实战验证。
